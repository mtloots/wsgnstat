# Package index

## All functions

Every exported entry point. The computation runs on a shared pure-C
back-end that is also bound from Python, and the two front ends are
checked against each other value by value.

- [`cfsgn()`](https://mtloots.github.io/wsgnstat/reference/cfsgn.md) :
  Characteristic function of the skew generalised normal distribution (C
  back-end)
- [`dsgn()`](https://mtloots.github.io/wsgnstat/reference/dsgn.md) :
  Density of the skew generalised normal distribution on the line (C
  back-end)
- [`dwsgn()`](https://mtloots.github.io/wsgnstat/reference/dwsgn.md) :
  Density of the wrapped skew generalised normal distribution (C
  back-end)
- [`fit_wsgn_mle()`](https://mtloots.github.io/wsgnstat/reference/fit_wsgn_mle.md)
  : Fit the wrapped skew generalised normal by maximum likelihood (C
  back-end)
- [`fit_wsgn_trig()`](https://mtloots.github.io/wsgnstat/reference/fit_wsgn_trig.md)
  : Fit the wrapped skew generalised normal by trigonometric moments (C
  back-end)
- [`psgn()`](https://mtloots.github.io/wsgnstat/reference/psgn.md) :
  Distribution function of the skew generalised normal distribution on
  the line (C back-end)
- [`pwsgn()`](https://mtloots.github.io/wsgnstat/reference/pwsgn.md)
  [`qwsgn()`](https://mtloots.github.io/wsgnstat/reference/pwsgn.md) :
  Distribution and quantile functions of the wrapped skew generalised
  normal distribution
- [`rsgn()`](https://mtloots.github.io/wsgnstat/reference/rsgn.md) :
  Random generation from the (wrapped) skew generalised normal
  distribution
- [`rwsgn()`](https://mtloots.github.io/wsgnstat/reference/rwsgn.md) :
  Random generation from the wrapped skew generalised normal
  distribution
- [`trig_moments()`](https://mtloots.github.io/wsgnstat/reference/trig_moments.md)
  : Population trigonometric moments of the wrapped family (C back-end)
